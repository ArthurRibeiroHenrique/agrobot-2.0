# Arquitetura React Native 
 
## Stack recomendada 
 
- React Native com Expo 
- TypeScript 
- Expo Router 
- TanStack Query 
- Zustand 
- Supabase 
- React Hook Form 
- Zod 
- NativeWind 
- Expo AV para audio 
- Expo FileSystem para arquivos 
- MMKV para armazenamento local 
- Sentry para erros 
- PostHog para analytics 
 
## Estrutura de pastas 
 
- src/app: telas e rotas 
- src/components: componentes visuais 
- src/services: API, Supabase, audio, analytics 
- src/hooks: regras reutilizaveis 
- src/store: estado global 
- src/lib: validacoes, constantes e utilitarios 
- src/types: tipos TypeScript
